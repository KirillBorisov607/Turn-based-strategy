Название: Код битвы

Описание проекта

Добро пожаловать в пошаговую тактическую стратегию, где игроки могут исследовать открытый мир, сражаться в тактических боях и управлять отрядами с уникальными механиками! Проект разработан с использованием Unreal Engine и предоставляет возможность адаптировать механики для создания собственных игр. В этой игре сочетаются элементы тактики, стратегии и управления ресурсами.
Предыстория

В далеком мире, разделенном на зоны, населенные различными видами существ, вспыхнула война за власть над древними артефактами. Эти артефакты дают их владельцам контроль над ресурсами мира и позволяют управлять его природой. Игрок берет на себя роль предводителя небольшого отряда, который должен исследовать мир, объединять союзников и участвовать в тактических боях, чтобы вернуть мир на свои земли.

Однако путь к победе нелегок. Игрокам предстоит управлять различными юнитами, каждый из которых имеет свои способности и ограничения, перемещаться через разнообразные ландшафты и решать, с кем сражаться, а с кем объединяться.
Механики игры
1. Основные механики

    Два режима игры:
        Тактический режим: Пошаговые сражения с использованием сетки (квадратной, шестиугольной, треугольной).
        Режим открытого мира: Свободное перемещение отрядов, управление группами юнитов, встреча с врагами.
    Типы действий:
        Перемещение юнитов.
        Использование заклинаний.
        Атака врагов.
        Исцеление союзников.

2. Сетка и типы плиток

    Типы сеток: Квадратная, шестиугольная, треугольная.
    Типы плиток:
        Обычные плитки: Доступны для всех юнитов.
        Плитки воды: Только для плавающих или летающих юнитов.
        Плитки с высокой стоимостью передвижения: Замедляют движение.
        Препятствия: Непроходимы для большинства юнитов.
    Модификаторы сетки: Используются для создания уникальных участков карты, таких как мосты, реки и зоны с высокой стоимостью передвижения.

3. Юниты

    Каждый юнит имеет:
        Скелетную сетку и анимации (движение, атака, использование заклинаний).
        Статистику (очки здоровья, действия, движения).
        Типы передвижения (пешие, летающие, плавающие).
        Заклинания: Например, атака мечом, исцеление, магические удары.
    Юниты управляются как игроком, так и искусственным интеллектом (ИИ).

4. Заклинания

    Типы заклинаний:
        Направленные заклинания.
        Заклинания с областью действия.
        Заклинания исцеления и атаки.
    Параметры заклинаний:
        Радиус действия.
        Стоимость выполнения.
        Анимации для визуального эффекта.

5. Боевая система

    Управляет:
        Состоянием сетки.
        Перемещением юнитов.
        Использованием заклинаний.
        Логикой действий ИИ.
    Поддержка индексов команд для разделения юнитов между игроком и ИИ.
    Тактический режим скрывает ненужные элементы окружения для улучшения видимости.

6. Окружение

    Генерация уровней с использованием сеток.
    Поддержка создания платформ, ступенек и других элементов окружения.
    Препятствия, деревья и кусты влияют на стратегию боя.

7. Искусственный интеллект

    Автоматическое управление юнитами ИИ.
    Реализация логики движения и взаимодействия с окружающей средой.
    Использование заклинаний для атаки и защиты.
