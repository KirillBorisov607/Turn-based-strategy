# План развития «Хранителей земель»

Рабочий план. Сделанное отмечается `[x]`, подробности о сделанном — в `ЖУРНАЛ_РАБОТ.md`.
Работа идёт в ветке `restart`; в `main` не сливаем и не пушим, пока автор не проверит.

## Где мы сейчас (октябрь 2026)

- Движок UE 5.8, проект `The_battle_code`. Логика поверх блюпринтов — C++-плагин `KeepersGame`,
  инструменты — `KeepersDevTools`, скрипты автоматизации — `Tools/Automation`.
- Есть:
  - бой на гексах с местностью: скала, порыв ветра, росток, корни, удар щитом;
  - намерения врагов; слизни делятся, куры зовут подмогу;
  - кампания «Зелёные долы»: карта из 7 колонок, 8 артефактов, босс;
  - обучение;
  - новое главное меню и единый стиль интерфейса.
- Тон игры: **смешное фэнтези**.

## Правило по ассетам

В проект попадают только ассеты с понятной лицензией:
- **CC0** (KayKit, Quaternius, Kenney);
- куплено через **Fab** и добавлено в проект из Epic Launcher;
- сделано самим автором.

Копии с сайтов-раздач (с файлами `info.txt` вида «библиотека ассетов здесь…») не используются.
Источник каждого пака записывается в таблицу внизу: она нужна для пояснительной записки к диплому.

- [ ] Убрать `Content/UltimateMenu` (пак, скорее всего, из того же источника) из ветки `restart`.
- [ ] Заменить то, что из него используется:

  - частицы дыма и пыли — на свои Niagara-эффекты.
- [ ] Проверить, что меню и бой работают без пака.

## Этап 1. Модели (ждёт решения автора)

Вариант А: **KayKit (CC0)**, нужно «да» на скачивание с itch.io или GitHub, около 50 МБ.
- [ ] KayKit **Adventurers**: рыцарь, маг, лучник, разбойник, варвар → наши герои.
- [ ] KayKit **Skeletons** и другие враги → враги регионов.
- [ ] KayKit **Medieval Hexagon Pack**: гекс-тайлы (трава, лес, горы, вода, реки, дороги, мосты) и здания.

Вариант Б: **Toony Tiny RTS Set с Fab**, если автор добавит его из своей библиотеки Fab.

Работа после выбора:
- [ ] Импорт; при необходимости общий скелет и ретаргет анимаций.
- [ ] Новые записи в `DT_DefaultUnitDataPerType`: модель, Anim BP с состояниями из `E_UnitAnimationState`, иконки.
- [ ] Заменить Стража, Следопыта и Друида; добавить новых героев: Мага, Разбойника, Варвара.
- [ ] Новые враги на регион: скелеты, разбойники, кто-то крупный для боссов.
- [ ] Портреты для HUD (рендер моделей в текстуры).

## Этап 2. Генерация карт боя

Цель: каждый бой — новая карта, но читаемая и честная.
- [ ] `KeepersMapGenerator`: по зерну и «биому» строит гекс-поле в `BP_Grid`.
  - Форма острова: шум плюс маска, без отрезанных кусков; проверка связности.
  - Слои местности: равнина, лес (дорога ×2), холмы и горы (непроходимо или ×3), вода и пропасть (только летающие), мосты.
  - Расстановка отрядов: старты на разных краях, честное расстояние, укрытия у обеих сторон.
  - Декор под тип тайла: деревья, камни, руины, здания.
- [ ] Биомы с правилами генерации:
  - луга;
  - лес;
  - болота (лужи замедляют);
  - горы (много обрывов, полезен порыв ветра);
  - зима (лёд скользит);
  - проклятые земли.
- [ ] Цели боя под генерацию:
  - победить всех;
  - продержаться N ходов;
  - защитить NPC;
  - дойти до точки;
  - уничтожить гнездо или тотем.
- [ ] Проверка генерации: автобой ИИ на 50 зёрнах, без застреваний и пустых карт.

## Этап 3. Кампания и сюжет (~20 часов)

Структура: **6 регионов × 2–3 часа**, плюс повторные забеги и концовки.
Регионы:
1. Зелёные долы (есть);
2. Шепчущий лес;
3. Солёные болота;
4. Ледяной перевал;
5. Город кур (столица заговора);
6. Сердце земель.

- [ ] Сюжетная арка. Хранители возвращают украденные «Камни земель». За кражей стоят куры-заговорщики, ими управляет Великий Петух. В финале выбор: вернуть камни духам земли, оставить себе или договориться с курами — три концовки.
- [ ] Регион:
  - своя карта узлов (генерируется);
  - местные враги и механика;
  - сюжетные узлы со сценами-диалогами;
  - босс с особой механикой.
- [ ] Диалоги: окно с портретом и репликами между боями, реплики героев в бою (уже есть механизм `KeepersBarks`).
- [ ] Новые типы узлов:
  - торговец;
  - тренер (новые способности);
  - событие с выбором и последствиями;
  - отдых (лечение);
  - испытание (сложный бой, лучшая награда).
- [ ] Прогресс героев:
  - уровни;
  - выбор новой способности или улучшения на уровне;
  - потери: раненый герой пропускает бой.
- [ ] Сохранение посреди региона, продолжение из меню (частично есть).

## Этап 4. Реиграбельность

- [ ] Каждый забег — новая карта регионов, новые бои, новые события.
- [ ] Выбор стартового отряда (3 из 6 героев) и разблокировка героев за достижения.
- [ ] 30+ артефактов, включая проклятые (сильные с минусом), и синергии между ними.
- [ ] Модификаторы сложности («Жар»): враги сильнее, больше кур, меньше лечения; награда — новые артефакты и скины.
- [ ] Ежедневный забег с общим зерном.
- [ ] Летопись: статистика забегов, открытые концовки, бестиарий.
